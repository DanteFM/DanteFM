### 📋 [Task Manager](https://github.com/DanteFM/task_manager)

Трекер задач с досками, статусами, тегами и приоритетами. Две роли: администратор создаёт доски и задачи и назначает исполнителей, исполнитель меняет статус своих задач. Авторизация через JWT в httpOnly-cookie. Проект развивается по стадиям, каждая стадия отмечена тегом в репозитории.

**Стек сейчас:** React, TypeScript, Ant Design, Node.js, Express, MongoDB, Zod, Docker

**Статус:** 🚧 в разработке. Бэкенд первой стадии готов, делаю клиент.

**План:** переезд бэкенда на Nest.js + PostgreSQL → Docker Compose и тесты → WebSocket-уведомления
